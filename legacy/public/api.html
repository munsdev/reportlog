Public API · version 1

The numbers, as data

Every aggregate figure ReportLog publishes is available as JSON. No key, no sign-up, no rate card. It is the same data the site’s own board is drawn from, computed once and served to both.

The site itself is closed while it is being finished. These figures are live and real, but the reports behind them are not public yet, so nobody can check a number against the record it came from. That changes at launch. Until then, treat these as a preview rather than something to build a story on.

Endpoints

AddressWhat it returns
GET /api/v1An index describing this API, its licence and its stability promise.
GET /api/v1/statsAggregate counts over the record. Cached 60 seconds.
curl https://reports.example.org/api/v1/stats

Any page may read it — Access-Control-Allow-Origin: * is set, so this works from a browser on your own site. Responses carry Cache-Control: public, max-age=60; please honour it rather than polling harder. There is a limit of 120 requests a minute per address, which is far more than anything reasonable needs.

Two rules about the numbers

There is no bare total, on purpose

Every count arrives already broken out — by outcome, by what a moderator concluded, by who filed it, by state, by subject. There is deliberately no single “incidents” figure to quote, because a lone number stripped of its context is how a record like this gets misused. If you need one number for a headline, use a published count together with the words that qualify it.

The denominator is visible

Reports that were declined, withdrawn, or are still under review are published alongside the ones that went out. You can compute our approval rate yourself, and watch it over time. That is the point: it turns “trust our moderation” into “audit our moderation”.

One asymmetry, stated rather than hidden: submissions never confirmed by email are not counted anywhere. They never entered the record, which is what stops anyone burning slots in someone else’s name.

Published is not the same as true. It means a moderator judged an account publishable, which is a weaker claim than true. This archive does not publish a verdict on whether an account is true. It used to: a by_veracity field recorded one of six conclusions, from pending to proven_true. That was withdrawn on 4 October 2026 — a one-word verdict about a named third party is the archive asserting a fact it cannot defend. Where a judgement is owed, the moderator who published the report writes a note instead.

The field is still here, and it now reads pending for everything. That is not a placeholder: it is the true count, because nothing assesses veracity any more. It is kept because the promise below says an existing field is not removed without a /api/v2, and breaking that quietly would stop somebody’s dashboard with no way to tell them. It will be gone at /api/v2. If you read it, stop reading it now rather than then.

What is in the response

FieldMeaning
as_ofWhen these figures were computed, ISO 8601 UTC.
confirmed_reports.by_dispositionEvery report that entered the record: published, under review, declined, unclear, withdrawn.
published_reports.by_veracityWithdrawn, and frozen. Reads pending for every report, which is the true count since nothing assesses veracity. Kept only to honour the stability promise; removed at /api/v2. An archive that recorded verdicts before 4 October 2026 still reports those honestly rather than having its own history rewritten.
published_reports.by_reporter_typeCredentialed observers against members of the public.
published_reports.by_account_typeWhether the reporter saw it themselves or was told about it.
published_reports.by_severityA moderator’s assessment where there is one, the reporter’s implication until then.
published_reports.by_stateCounted once per state, so a report covering three states counts three times. These add to more than the report total, deliberately.
published_reports.by_category_groupSubject areas with readable labels. A report counts in every group it touches, at most once each.
published_reports.corroborationHow many published accounts have another account of the same incident.
releaseWhich release of the site produced these.

Stability

The shape under /api/v1 is a promise. Fields may be added. Existing fields will not be renamed, retyped or removed without a new version at /api/v2, and both would run side by side for a while. Something you build today should still work in a year, because there is no way for us to tell you if it stopped.

Licence

The figures and the consent wordings on this page are CC BY 4.0. Use them anywhere, including commercially; credit ReportLog. If you publish a figure, saying when you fetched it costs you nothing and saves an argument later.

The reports themselves are not covered, and we could not cover them if we wanted to. Each one is its author's own account, published here because they permitted that. Their permission is not ours to hand on, so nothing here licenses you to republish report content — this page serves counts and wordings, not accounts.

<script>
(function () {
  var API = 'https://reports.example.org/api/v1/stats';
  var el = document.getElementById('reportlog-stats');
  var esc = function (s) {
    return String(s).replace(/[&<>"]/g, function (c) {
      return { '&': '&amp;', '<': '&lt;', '>': '&gt;', '"': '&quot;' }[c];
    });
  };
  var n = function (v) { return (v || 0).toLocaleString(); };

  // Rows, biggest first, with a class so published reads teal and declined
  // reads crimson — the same two colours those states have on the site.
  function rows(obj, labels, classes) {
    var keys = Object.keys(obj || {}).sort(function (a, b) { return obj[b] - obj[a]; });
    if (!keys.length) return '<p class="el-note">Nothing yet.</p>';
    return '<ul class="el-rows">' + keys.map(function (k) {
      return '<li class="el-row ' + ((classes || {})[k] || '') + '">'
        + '<span>' + esc((labels || {})[k] || k.replace(/_/g, ' ')) + '</span>'
        + '<span class="el-n">' + n(obj[k]) + '</span></li>';
    }).join('') + '</ul>';
  }

  function chips(obj, labels) {
    var keys = Object.keys(obj || {}).sort(function (a, b) { return obj[b] - obj[a]; });
    if (!keys.length) return '<p class="el-note">Nothing yet.</p>';
    return '<div class="el-grid">' + keys.map(function (k) {
      return '<div class="el-chip"><b>' + n(obj[k]) + '</b><span>'
        + esc((labels || {})[k] || k) + '</span></div>';
    }).join('') + '</div>';
  }

  var VERACITY = {
    pending: 'Not yet assessed', undetermined: 'Undetermined',
    likely_true: 'Likely true', proven_true: 'Proven true',
    likely_false: 'Likely false', proven_false: 'Proven false',
  };
  var DISPOSITION = {
    published: 'Published', under_review: 'Still under review',
    declined: 'Declined', unclear: 'Unclear', withdrawn: 'Withdrawn by the reporter',
  };

  fetch(API, { cache: 'no-store' })
    .then(function (r) { if (!r.ok) throw new Error(r.status); return r.json(); })
    .then(function (d) {
      var p = d.published_reports || {};
      var groups = {};
      Object.keys(p.by_category_group || {}).forEach(function (k) {
        groups[p.by_category_group[k].label] = p.by_category_group[k].count;
      });

      el.innerHTML =
        '<div class="el-card">'
        + '<p class="el-eyebrow">Your archive &middot; live</p>'
        + '<h2>The record so far</h2>'
        + '<p class="el-note">' + esc(d.note || '') + '</p>'

        + '<h3>Every confirmed report</h3>'
        + rows((d.confirmed_reports || {}).by_disposition, DISPOSITION,
               { published: 'el-pub', declined: 'el-dec' })
        + '<p class="el-note">' + esc((d.confirmed_reports || {}).excludes || '') + '</p>'

        + '<h3>Published reports, by what a moderator concluded</h3>'
        + rows(p.by_veracity, VERACITY)

        + '<h3>Who filed them</h3>'
        + rows(p.by_reporter_type,
               { credentialed_observer: 'Credentialed observers', member_of_public: 'Members of the public' })
        + rows(p.by_account_type,
               { direct: 'Saw it themselves', secondhand: 'Reported to them by someone else' })

        + '<h3>What they were about</h3>'
        + rows(groups)

        + '<h3>By state</h3>'
        + chips(p.by_state)

        + '<h3>Corroboration</h3>'
        + rows((p.corroboration || {}),
               { corroborated_accounts: 'Accounts with another account of the same incident',
                 single_accounts: 'Accounts standing alone',
                 distinct_incidents_with_multiple_accounts: 'Incidents with more than one account' })

        + '<p class="el-foot">As of ' + esc(new Date(d.as_of).toUTCString())
        + '. Figures from <a href="https://reports.example.org">reports.example.org</a>'
        + (d.release ? ' (' + esc(d.release) + ')' : '') + '. '
        + esc(d.licence || '') + '.</p>'
        + '</div>';
    })
    .catch(function () {
      el.innerHTML = '<div class="el-card"><p class="el-err">The live figures could not be '
        + 'loaded just now. They are always available at '
        + '<a href="https://reports.example.org/api/v1/stats">reports.example.org/api/v1/stats</a>.</p></div>';
    });
})();
</script>
