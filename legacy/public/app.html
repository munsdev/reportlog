ReportLog

Install the app for quick access, or use it straight from your browser — both work exactly the same.

Use in browser

Install on iPhone or iPad

  1. Open this site in Safari.
  2. Tap the Share icon (square with an arrow pointing up).
  3. Scroll down and tap Add to Home Screen.

Install on Android

  1. Open this site in Chrome.
  2. Tap the menu (⋮) in the top right.
  3. Tap Install app (or Add to Home screen).

On a computer

  1. Open this site in Chrome or Edge.
  2. Click the install icon in the address bar, or use the browser menu and pick Install app.
