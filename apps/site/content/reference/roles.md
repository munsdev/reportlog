## What each role reaches

| Area                                                                                    | Moderator | Access Manager | Administrator                  | Owner                    |
| --------------------------------------------------------------------------------------- | --------- | -------------- | ------------------------------ | ------------------------ |
| Moderation: queue, flood screen, tip links, list review, illegal content notices, files | Yes       |                | Yes, after the agreement       | Yes, after the agreement |

| Roles and organizations                                                                 |           | Moderators     | Moderators and Access Managers | Everybody                |
| Who is doing what, who granted what, testers                                            |           | Yes            | Yes                            | Yes                      |
| Transparency log, updates, who opened protected data                                    |           |                | Yes                            | Yes                      |
| Backups and exports, journalists                                                        |           |                |                                | Yes                      |

Journalists reach the journalist desk and nothing else. Organization coordinators reach their organization's intake. Anybody signed in reaches My reports, email updates and their own account.
